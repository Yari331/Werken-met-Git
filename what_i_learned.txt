Evaluatie Git Workshops - Darian

Wat ik heb geleerd tijdens de afgelopen 3 workshops:
Voordat we aan deze workshops begonnen, was Git voor mij nog helemaal nieuw. In de afgelopen weken heb ik geleerd hoe handig Git is om samen aan code te werken. Het meest leerzame vond ik het werken met branches. Het is heel fascinerend om te zien hoe je in een eigen 'zijtak' kunt werken aan je eigen code, zonder dat je meteen de hoofdcode van het project in de war schopt.

Wat ik nog zou willen weten/leren over Git:
In de toekomst zou ik graag willen leren hoe je heel grote projecten netjes ordent met Git. Als een project groeit en er honderden bestanden en tientallen branches komen, lijkt het me een grote uitdagig om het overzicht te bewaren. Ik ben benieuwd welke mappenstructuur en Git-regels grote bedrijven daarvoor gebruiken.



Evaluatie Git Workshops - Yari

Wat ik heb geleerd tijdens de afgelopen 3 workshops:
Ik heb tijdens de workshops goed geleerd hoe branches werken en hoe je onafhankelijk van elkaar aan hetzelfde project kunt werken. Vandaag heb ik in de praktijk ervaren hoe een merge-conflict ontstaat en hoe je deze handmatig in de code moet oplossen als Git er zelf niet uitkomt.

Wat ik nog zou willen weten/leren over Git:
Ik zou in de toekomst nog wel meer willen weten over geavanceerde functies, zoals rebasen, of wat je moet doen als je per ongeluk een verkeerde commit hebt gepusht en die weer netjes ongedaan wilt maken.
